# Браузер для Resolume Arena

FFGL-источник для macOS: показывает веб-страницы в Arena и открывает отдельное окно для кликов, ввода текста и прокрутки.

## Звук страницы

В настройках источника включи **Звук браузера**, выбери устройство CoreAudio и стереопару. Поддерживаются многоканальные устройства и пары 1/2, 3/4, 5/6 и далее. По умолчанию звук выключен.

Звук выводится плагином напрямую на выбранные каналы устройства macOS, в обход аудиомикшера Arena. Для захвата требуется macOS 14.2+ и разрешение Arena на запись системного звука.

## Использование

1. В Arena открой `Sources` и выбери **Браузер**.
2. Введи URL и нажми **Открыть**. Поддерживаются `http://`, `https://` и `file://`.
3. Нажми **Веб-окно**, чтобы взаимодействовать со страницей.
4. Настрой аудиоустройство и каналы в группе **Аудиовыход**.

## Сборка

Нужны macOS 14.2+ и CMake 3.20+. Универсальная сборка Apple Silicon/Intel:

```sh
cmake -S . -B build -DPLUGIN_VERSION=1.0.0 -DUPDATE_MANIFEST_URL=
cmake --build build --target BrowserSource --parallel 4
```

Скопируй `build/BrowserSource.bundle` в `~/Documents/Resolume Arena/Extra Effects/` и перезапусти Arena.
